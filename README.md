# היסטוריית הסקרים של ישראל

אתר סטטי (HTML, CSS ו-JavaScript בלבד, בלי שלב בנייה) על שמונה מערכות הבחירות לכנסת 2009–2022, ועל הבחירות לכנסת ה-26 (אוקטובר 2026) לפני יום הבחירות:
תוצאות, חלוקת מושבים, גושים, המלצות לנשיא, תעודת זהות לכל רשימה בכל מערכת, ארכיון הסקרים, דירוג דיוק הסוקרים ובונה קואליציות.

## הרצה
- מקומית: לפתוח את `index.html` בדפדפן (לחיצה כפולה). אין צורך בשרת.
- אחסון: להעלות את כל התיקייה כמו שהיא ל-Netlify (האתר מחובר ל-Netlify דרך GitHub).
- כתובות: באינטרנט הקישורים נקיים (`/election?e=2022`, בלי `.html`); `_redirects` אומר ל-Netlify איזה קובץ להגיש. כשפותחים מהתיקייה (`file://`) הקישורים מצביעים על הקבצים עצמם. באחסון אחר צריך להגדיר את אותן הפניות.
- נדרש חיבור לאינטרנט לגופנים (Google Fonts) ולתמונות (ויקישיתוף). בלי חיבור האתר עובד, עם גופן חלופי וראשי תיבות במקום תמונות.

## עדכון הנתונים
קבצי `data/*.js` נוצרים אוטומטית. כדי לבנות אותם מחדש (Python 3 ו-openpyxl):

```
python3 tools/scripts/make_raw_2026.py
python3 tools/scripts/build_site_data.py .
python3 tools/scripts/verify_site.py downloads/polls-2009-2022.xlsx .
```

הבדיקה השנייה משווה כל ממוצע, גוש, מדגם וערך סקר באתר מול הערכים המחושבים בקובץ האקסל.
החלטות המיפוי (רשימה ← סיעות, אותיות, המלצות, מיקום פוליטי) נמצאות ב-`tools/scripts/sitecfg.py`.
המספרים של הסקרים כפי שנקראו בפרסום המקורי (וסקרים שעוד לא בוויקיפדיה) נמצאים ב-`tools/data/primary_polls.txt`; הם גוברים על ויקיפדיה. הפורמט מתועד בראש `tools/scripts/primary.py`.

## אבטחה
- האתר סטטי לגמרי: אין טפסים, אין שרת, אין מסד נתונים, אין שמירה בדפדפן ואין שליחת נתונים. מבקר לא יכול לשנות שום דבר באתר.
- כל טקסט שמוצג עובר escaping, ופרמטרים בכתובת (`?e=`, `?p=`) משמשים רק לחיפוש ברשימה קבועה.
- בכל עמוד יש Content-Security-Policy שמתירה להריץ רק קבצי JavaScript מתוך התיקייה, וחוסמת קוד מוזרק, טפסים ומסגרות.
- `_headers` מוסיף כותרות אבטחה ב-Netlify וב-Cloudflare Pages, כולל חסימה של הטמעת האתר בתוך אתר אחר.
- **גופנים ותמונות:** כברירת מחדל הם נטענים מ-Google Fonts ומוויקישיתוף. כדי שהאתר לא יתלה באף שרת חיצוני, יש להריץ פעם אחת, במחשב עם אינטרנט:

  ```
  python3 tools/scripts/localize_assets.py .
  ```

  ב-Windows: `py tools/scripts/localize_assets.py .` (מתוך התיקייה של האתר). אפשר להריץ שוב בכל עת; אחרי עדכון שמוסיף אנשים חדשים הוא מוריד רק את התמונות החדשות.

  הסקריפט מוריד את הגופנים ואת התמונות לתוך התיקייה, ומצמצם את ה-CSP לקבצים של האתר בלבד.
- **מי שיכול לשנות את האתר הוא מי שיש לו גישה לקבצים או לחשבון האחסון.** כדאי להפעיל אימות דו-שלבי בחשבון (GitHub / Netlify).
- התיקייה `tools/` לא נחוצה לאתר עצמו. אפשר להעלות אותה (אין בה מידע רגיש) או להשאיר אותה רק אצלך.
